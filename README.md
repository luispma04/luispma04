### Model Predictive Control & State Estimation

Design, simulation and experimental validation of a
constrained Model Predictive Controller on a physical
thermal system.

- Experimental system identification
- Dense and sparse quadratic programming formulations
- Kalman filtering and disturbance estimation
- Constrained reference tracking
- Experimental comparison with conventional PI control

**Experimental results:**

| Metric | Result |
| :--- | :--- |
| Steady-state tracking error | 0.09–0.18 °C |
| Prediction horizon | 50 steps / 250 s |
| Short-run actuation oscillation reduction | 80.5% |

**Stack:** MATLAB, Mathematical Optimization, Control Systems

[View Repository](https://github.com/luispma04/ECPD)
· [Final Implementation](https://github.com/luispma04/ECPD/tree/final)
